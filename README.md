# Wucius Wong: Principles of Two-Dimensional Design
### Interactive Generative Studio & Pedagogical Companion

A web application for learning and practicing the foundational visual grammar from **Wucius Wong's** classic textbook *"Principles of Two-Dimensional Design"* (*Fundamentos del diseño bi- y tridimensional*).

---

## Features

- **All 12 2D Design Chapters Covered:**
  1. **Introduction to Visual Language:** Conceptual, visual, relational, and practical elements within the picture frame.
  2. **Form & The 8 Interrelations:** The 8 fundamental relational operations (Detachment, Touching, Overlap, Penetration, Union, Subtraction, Intersection, Coincidence) with positive/negative figure-ground inversion.
  3. **Repetition:** Unit forms, sub-units, super-units, reflection, rotational symmetry, and the classic "Meeting of 4 Circles".
  4. **Structure:** Formal, semi-formal, and informal structures; active vs. inactive cell clipping; visible vs. invisible grids; sheared, sliding, and curved grid variations.
  5. **Similarity:** Visual kinship, imperfection/truncation, 3D spatial foreshortening, and elastic tension/compression.
  6. **Gradation:** Planar rotation/translation, spatial depth, shape morphing (circle to triangle/square), parallel/concentric/zigzag pathways, and alternating opposing gradations.
  7. **Radiation:** Centrifugal sunbursts, swirling vortices, concentric ripples, centripetal convergence, and dual-center optical Moiré interference.
  8. **Anomaly:** Intentional irregularity, focal point epicenters (click canvas to place epicenter), and tectonic structural fractures.
  9. **Contrast:** Qualitative and quantitative comparisons (scale, shape, direction, value) with an asymmetric balance scale.
  10. **Concentration:** Quantitative module population, gravitational attractors/repulsors, point/line concentration, voids, and free clustering.
  11. **Texture:** Visual vs. tactile texture, decorative wave patterns, mechanical halftone screens, and Wong's iconic typographic collage raster.
  12. **Space:** Flat vs. illusory space, isometric perspective cubes, fluctuating reversible planes, and conflicting/impossible optical paradoxes.

- **Swiss / Bauhaus Aesthetic:** High-contrast editorial layout with clean typography (Space Grotesk & Inter) and customizable color palettes (*Ink & Paper*, *Chalkboard*, *Bauhaus Primary*, *Architectural Blueprint*, *Editorial Archive*).
- **Interactive Workbench:**
  - Real-time generative HTML5 canvas with retina crispness.
  - Interactive click and drag manipulation (placing anomaly epicenters and concentration attractors).
  - Presets modeled directly on figures from the original book.
  - Studio practice assignments with target design goals for every chapter.
  - Instant High-Res PNG and vector SVG export.

## How to Run

The app is built with modern ES modules and zero build dependencies:

```bash
# Serve locally using Python
python3 -m http.server 8080
```

Then open your browser to:
[http://localhost:8080](http://localhost:8080)

Or open `index.html` directly in any modern web browser.
